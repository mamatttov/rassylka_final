# Рассылка расчётных листков

Каждый месяц бухгалтерия выгружает из 1С «Расчетную ведомость» по зарплате, и раньше листки
каждому сотруднику приходилось собирать и отправлять вручную. Эта программа делает это сама:
читает ведомость, формирует для каждого сотрудника расчётный листок в Excel и отправляет его
на рабочую почту.

## Что умеет

- читает ведомость из 1С в Excel как есть: месяц и название организации берёт из шапки;
- читает и простую таблицу CSV/Excel (пример в `sample/vedomost.csv`);
- расшифровывает сокращения 1С (ПФР, ГНПФР, ПН), взносы работодателя в листок не попадают;
- сверяет «к выплате» с «Сальдо на конец» и ругается на отрицательные суммы;
- email сотрудников хранит в `sotrudniki.xlsx`, новых сотрудников дописывает туда сама;
- по умолчанию ничего не отправляет: сначала пробный запуск, потом тест себе, потом рассылка;
- ведёт журнал отправок, чтобы никому не прислать листок дважды.

## Установка

```
pip install -r requirements.txt
copy smtp.example.ini smtp.ini        # и вписать свою почту
```

Пароль в файлах не хранится. Для Gmail нужен пароль приложения
(https://myaccount.google.com/apppasswords), его задают перед запуском:

```
$env:BUH_SMTP_PASSWORD="пароль приложения"
```

Проверить подключение к почте: `python smtp_check.py`

## Каждый месяц

```
python main.py "ведомость ЗП ноя.xlsx"                         # 1. пробный запуск, смотрим листки
python main.py "ведомость ЗП ноя.xlsx" --test-to я@почта.kg    # 2. все письма себе
python main.py "ведомость ЗП ноя.xlsx" --send                  # 3. рассылка (спросит «да»)
```

Полезное: `--only Иванов,Петров` — только этим сотрудникам, `--resend` — отправить повторно.
Для CSV месяц указывается вручную: `--period 2026-11`.

## Из чего состоит

| файл | что делает |
|---|---|
| `main.py` | запуск, порядок действий |
| `vedomost.py` | чтение ведомости (1С и простая таблица) |
| `sotrudniki.py` | справочник email сотрудников |
| `listok.py` | расчётный листок в Excel |
| `pochta.py` | письмо и подключение к почте |
| `zhurnal.py` | журнал отправок (SQLite) |
| `utils.py` | суммы, месяцы, чтение CSV/Excel |
| `smtp_check.py` | проверка настроек почты |
